现有人偶：中立与两个极限方向

这是提交 046564c 的原有 SVG 隔离复现，不是改造后的效果图。

每格左侧为 2 倍放大，右侧为原来的 96 × 126 CSS 像素。保留原始几何、颜色、头部与瞳孔变换；关闭整体上下漂浮，便于检查眼睛。未启动完整 Electron 应用。

正视

x = 0, y = 0

右上极限

x = +1, y = −1

右下极限

x = +1, y = +1
在页面内移动鼠标x = 0.00
y = 0.00

这个区域使用原始归一化算法：相对人偶中心，除以人偶自身半宽 / 半高。
鼠标离开小人偶的矩形范围后，对应方向就会达到 ±1。
